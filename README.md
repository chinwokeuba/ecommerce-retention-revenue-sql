# Customer Retention & Revenue Intelligence (SQL)

End-to-end MySQL analysis of an online retailer's transactions
(541,909 rows, Dec 2010 to Dec 2011).

## Key findings
- 6.3% of customers (High Value) generate 53.9% of revenue
- Cancellations are 10.1% of gross revenue, but most is fees and
  two reversed bulk orders; ordinary product cancellations are about 2.7%
- Only 15% to 24% of customers acquired in 2011 bought again the next month

## SQL skills used
GROUP BY, WHERE/HAVING, JOINs, subqueries, CTEs, window functions
(RANK, LAG), date and string functions, CASE WHEN
